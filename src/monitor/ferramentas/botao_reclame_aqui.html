Botão do Reclame Aqui

Captura os indicadores da aba 6 meses da página de cada empresa, no seu próprio navegador, e gera um arquivo para o monitor importar-reclame-aqui. Lista gerada em __GERADO_EM__ com __TOTAL__ empresas.

📌 Monitor RA

Instalar (uma vez)

  1. Mostre a barra de favoritos (Ctrl+Shift+B no Chrome e no Edge).
  2. Arraste o botão azul acima para a barra de favoritos.

Usar (uma vez por mês)

  1. Abra a página de uma empresa, por exemplo reclameaqui.com.br/empresa/nubank, com a aba 6 meses selecionada (é a padrão).
  2. Clique em 📌 Monitor RA na barra de favoritos. Um painel confirma a captura e lista as empresas que faltam, com links.
  3. Repita até o painel dizer que não falta nenhuma e clique em Baixar arquivo.
  4. No PowerShell, na pasta do projeto:
    uv run monitor importar-reclame-aqui "$HOME\Downloads\reclame_aqui_AAAA-MM-DD.json"
  5. Depois de importar, clique em Limpar no painel para começar o próximo mês do zero.

O botão só lê os números do painel de reputação. Não lê reclamações nem dados de consumidores.
